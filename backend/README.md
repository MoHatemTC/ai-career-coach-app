# Backend

This folder will contain the API, business logic, prompts, data models, and tests.

Interns should create implementation files as part of assigned tasks.

## Folder Guide

- `routes/` - API endpoints.
- `services/` - business logic.
- `models/` - data models.
- `prompts/` - AI prompts.
- `tests/` - automated tests.

## Rule

Do not put all logic in one file. Keep routes small and move reusable logic into services.
