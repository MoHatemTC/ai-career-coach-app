# Prompts

Create AI prompt templates here.

Examples interns may create:

- `profile_analysis.md`
- `job_matching.md`
- `skill_gap.md`
- `cover_letter.md`

## Prompt Rules

- One prompt per file.
- Do not hard-code prompts inside Python files.
- Include the expected output format.
- Ask for JSON when the backend needs structured data.
- Tell the AI not to invent skills, experience, dates, companies, or achievements.
- Mention which service uses the prompt.
