# Starter Tasks

These tasks are intentionally not implemented in the scaffold. Interns should create the needed files as part of the learning process.

## Backend Tasks

- Create the first FastAPI app entry point.
- Create a health check route.
- Create a CV parser service.
- Create a job loader that reads from sample JSON.
- Create a matching service with simple scoring.
- Create an AI client wrapper.
- Create prompt files for profile analysis and job matching.
- Add backend tests for each service.

## Frontend Tasks

- Create the first React app.
- Create a dashboard page.
- Create a CV upload page.
- Create a job matches page.
- Create reusable components for job cards and score badges.
- Connect the frontend to the backend health endpoint.

## Documentation Tasks

- Update setup instructions after backend commands exist.
- Document each API endpoint as it is created.
- Document required environment variables.
- Add screenshots for frontend flows when available.

## Integration Tasks

- Add backend and frontend services to `docker-compose.yml`.
- Update CI to run backend tests.
- Update CI to run frontend checks.
- Add sample data for local demos.
